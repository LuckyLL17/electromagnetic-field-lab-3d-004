# ElectroMag Lab · 3D

基于 React、Vite、TypeScript、Three.js 与 React Three Fiber 的专业 3D 可视化实验平台。

## 双视图对照实验台

主实验台扩展为左右两个可比较的三维视图（A / B）：

- **独立状态**：两侧各自保存场型（电偶极子 / 螺线管 / 平行板电容器）、激励强度与场矢量开关；配置修改互不影响。
- **交换配置**：顶栏「⇄ 交换配置」仅交换两侧场型/强度/矢量，相机姿态留在各自窗口。
- **相机联动 / 独立**：
  - 联动时两侧保持同一世界视角（方位角、极角、距离一致），任一视图旋转/缩放实时同步；开启瞬间以左视图对齐，并自动拉远到两侧模型都能完整取景的距离。
  - 独立时为双相机，旋转、缩放、重置严格隔离，一侧无法污染另一侧。
- **完整取景**：换场型、窗口缩放均按模型包围尺寸与画布宽高比重算相机距离（`fitDistance`）；联动时取两侧所需距离的最大值。
- **单侧重置**：每侧「↺ 重置本侧视角」只复位自己的相机；联动模式下重置作用于共享视角。
- **窄屏降级**：宽度 ≤ 1180px 时两视图改为上下堆叠、控制栏移至下方（≤ 680px 进一步紧凑化），画布按竖长宽高比自动重新取景。

### 架构取舍

- 采用「双独立 Canvas + 双相机」而非共享相机：两个 R3F 场景树中的场景对象（网格、材质、控制器）完全隔离，避免共享相机时两个渲染器争抢 aspect / 投影矩阵；联动由纯数据的 `CameraBridge`（球坐标 azimuth/polar/distance）转发。
- `src/dual-view.ts` 不依赖 three，封装全部协同规则；`src/scene.tsx` 中的 `ViewRig` 是每侧唯一的相机控制组件，只通过 `ControlsPort` 与桥通信。

## 启动

```bash
npm install
npm run dev
```

开发端口：`5176`。

## 验证

```bash
npm run verify   # 45 项断言：交换、联动切换/解除、单侧重置、取景与窄屏降级
npm run build    # 类型检查 + 生产构建
```

项目仅实现前端基础实验流程，后续可扩展真实 CFD / FEM 数据导入、网格解析、测量工具和实验结果导出。
